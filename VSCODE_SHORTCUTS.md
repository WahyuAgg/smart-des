# VS Code Shortcuts

## Most Used

- `F12` → Go to Definition
- `Alt + ←` → Back
- `Alt + →` → Forward
- `Ctrl + P` → Find File
- `Ctrl + Shift + O` → Find Method
- `Ctrl + Tab` → Recent File
- `Shift + F12` → References
- `Ctrl + Shift + F` → Search Project

## Navigation

| Shortcut | Action |
|----------|--------|
| `Alt + ←` | Go Back |
| `Alt + →` | Go Forward |
| `F12` | Go to Definition |
| `Alt + F12` | Peek Definition |
| `Shift + F12` | Find References |

| Shortcut | Action |

## Symbols

| Shortcut | Action |
|----------|--------|

## Search

| Shortcut | Action |
|----------|--------|
| `Ctrl + Shift + F` | Search in Workspace |
| `Ctrl + F` | Search in Current File |
| `Ctrl + H` | Replace in Current File |

## Editing

| Shortcut | Action |
|----------|--------|

| `Shift + Alt + ↓` | Duplicate Line |
| `Ctrl + /` | Toggle Comment |
| `Shift + Alt + F` | Format Document |
